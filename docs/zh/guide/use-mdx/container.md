# 容器

你可以使用 `:::` 语法来创建自定义容器，且支持自定义标题。


## 例子

:::tip
这是一个 `block` 类型为 `tip`
:::

:::info
这是一个 `block` 类型为 `info`
:::

:::warning
这是一个 `block` 类型为 `warning`
:::

:::danger
这是一个 `block` 类型为 `danger`
:::

::: details
这是一个 `block` 类型为 `details`
:::

:::tip 自定义标题写法1
这是一个 `block` 标题为 `自定义标题写法1`
:::

:::tip{title="自定义标题写法2"}
这是一个 `block` 标题为 `自定义标题写法1`
:::
